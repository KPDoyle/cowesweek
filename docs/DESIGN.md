# Cowes Week Live — island identity

An original visual identity informed by award-recognised boating websites and Isle of Wight destination branding. This app remains an independent concept; it does not use official tourism, yacht-company or Cowes Week logos, copy or photography.

## Original system

| Token | Colour | Role |
| --- | --- | --- |
| Deep sea | `#091f42` | Navigation, image shading |
| Azure | `#1763db` | Primary actions, selected event, links |
| Chalk | `#fffdf5` | Image text and warm surfaces |
| Sunshine | `#ffdc52` | Hero action, island motif, highlights |
| Sea glass | `#d7efe8` | Upcoming-start card |
| Ink | `#122b50` | Main text |
| Slate | `#5d718c` | Secondary text |

Manrope supplies bold, rounded headlines; DM Sans keeps race records legible. The app's copy, logo and artwork are original. Both sailing and offshore powerboat panoramas are AI-created illustrations, labelled in the interface, rather than documentary photographs or navigational information. They are compressed WebP assets with Next.js responsive image loading. No external yacht imagery is reused.

The live view begins with an island story and actions into the existing programme, boat registration and harbour workspace. Below it, the race centre retains tracking, results, conditions, replay and venue mode. Other sections share the palette, typography and clearer form/table styles. Mobile navigation, keyboard focus and reduced-motion support are retained. Event records, scoring, private storage and authentication are unchanged.
